# Constela Site

Landing page for the Constela app, built with Next.js 16, Tailwind CSS v4, and shadcn/ui (radix-maia style). The visual language, theme tokens, and component patterns are inherited from `constela-web` / `Constela-website`.

## Stack

- Next.js 16 (App Router)
- TypeScript
- Tailwind CSS v4
- shadcn/ui (radix-maia preset, olive base)
- lucide-react icons
- next-themes (light / dark, hotkey `d`)

## Getting started

```bash
npm install
npm run dev
```

Then open http://localhost:3000.
